Week 05

AI 怎麼記得前面說過什麼？

2026-10-19

✏️ 一句話重點

Prompt 只有兩個要點：正確的資訊＋清楚的指引。

💡 核心概念

Prompt 必殺技

先叫 AI 不要寫程式，而是問我問題、幫我釐清需求，最後一起寫出規格書。

規格書

把功能、風格、使用情境寫清楚，AI 才能照著做出符合想像的網頁。

單一 index.html

HTML 決定內容、CSS 決定外觀、JavaScript 讓網頁能互動，都可以寫在同一個檔案。

GitHub Pages

把 index.html 上傳到 GitHub repo，開啟 Pages 就有公開網址。

🛠️ 我的作業

做了「今天吃什麼？扭一顆！政大版」：轉動扭蛋機把手隨機抽出政大附近的店家，可依類別、預算篩選，會排除最近吃過的。

成品網址：daisyyy33.github.io/what-to-eat

🕳️ 踩過的坑

  • 剛開 GitHub Pages 會先出現 404，要等 1–3 分鐘部署完成。
  • 網址要打完整，要包含 repo 名稱 /what-to-eat/。

🌱 一句心得

規格書寫得越清楚，AI 做出來的東西就越接近我想要的。
